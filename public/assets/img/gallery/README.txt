Gallery images
==============

Drop photos straight into this folder. That is the whole process.

  - Any filename, any of .jpg .jpeg .png .webp (upper or lower case)
  - No categories, no filters, no markup to edit
  - Sorted naturally by filename, so a 01_ / 02_ prefix controls the order
  - While this folder is empty the page falls back to theme stock images

Captions come from the filename, so "edinburgh-2019.jpg" shows as
"Edinburgh 2019". Camera dumps (IMG_1234.jpg, DSC0042.jpg) get no caption
rather than an ugly one.
